# Sistem Pakar Diagnosis Penyakit Tanaman Padi (Forward Chaining)
UTS Sistem Pakar - TI22604

Jalankan: buka folder di VS Code, klik kanan `index.html` > Open with Live Server (atau klik dua kali `index.html`).

- `js/knowledge.js` : fakta, kesimpulan, aturan, sumber, skenario uji
- `js/engine.js`    : mesin inferensi Forward Chaining
- `js/ilustrasi.js` : ilustrasi SVG penyakit
- `js/app.js`       : antarmuka
- `img/`            : taruh foto asli D1.jpg ... D7.jpg (otomatis menggantikan ilustrasi)

Yang harus dilengkapi: wawancara (S6), verifikasi pemetaan sumber, NIM dan nama di laporan.
